# PlaywrightMCP

Automation testing framework built using Playwright and Python.

## Features

* UI Automation Testing
* Login and Logout Validation
* Page Object Model (POM)
* Screenshot Capture
* Test Reporting

## Prerequisites

* Python 3.10+
* Playwright

## Installation

```bash
git clone https://github.com/choubeyayushi20-oss/PlaywrightMCP.git
cd PlaywrightMCP

pip install -r requirements.txt
playwright install
```

## Run Tests

```bash
python main.py
```

## Project Structure

* tests/ - Test cases
* pages/ - Page Object classes
* utils/ - Utility functions
* test_data/ - Test data files
* reports/ - Generated reports
* screenshots/ - Failure screenshots
